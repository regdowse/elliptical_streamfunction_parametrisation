# Idealised and supplementary experiments

These scripts reproduce the manuscript's controlled tests using the shared
estimators in [`functions.py`](../functions.py). They require the dependencies
in the [root README](../README.md#installation), without Jupyter or external data.
Run commands from the repository root.

## Run the experiments

```bash
# Main idealised tests and ESP schematic: Figures 1–5, 7–8 and 11.
python3 experiments/run.py idealised

# Supplementary noise/sampling and background-flow tests: Figures S1–S3.
python3 experiments/run.py all
```

The selectors are independent: `all` runs the two supplementary experiments;
`idealised` runs SOLO, DOPPIO, LATTE and the schematic. To run one group:

```bash
python3 experiments/run.py solo_idealised
python3 experiments/run.py doppio_idealised
python3 experiments/run.py latte_idealised
python3 experiments/run.py schematic
python3 experiments/run.py noise_sampling
python3 experiments/run.py background_flow
```

## Configurations and test designs

Main groups have individual JSON files in [`configs/`](configs/). The supplementary
tests share [`sensitivity.json`](configs/sensitivity.json), including their sampling
coordinates, perturbation levels, random seed and plotting settings. Fits use SI
units; plotted positions are in kilometres. All groups use Gaussian truth with
**Rc = 85 km**, **streamfunction amplitude = 250,000 m²/s** and centre **(0, 0)**.

### SOLO — Figures 2–5

Configuration: [`solo_idealised.json`](configs/solo_idealised.json).
The base eddy is circular. P1–P3 use 140-km transects at cross-track offsets
20/50/80 km. L1–L3 use full lengths 80/140/200 km at a 20-km offset. Observations
are spaced 10 km apart. The deformation test uses 17 determinant-one matrices,
spanning aspect ratios 1–3, with a fixed transect.

Figure 2 is a **conceptual inner-core illustration**: SOLO receives ideal
constant/linear inner-core velocities, while MOCA receives Gaussian velocities.
It illustrates the method's construction, rather than comparing recovery from
identical observations. Figures 3–4 use the synthetic Gaussian observations.

### DOPPIO — Figures 7–8

Configuration: [`doppio_idealised.json`](configs/doppio_idealised.json).
The elliptical truth uses Q proportional to `[[1, 0.4], [0.4, 1]]`, normalised to
determinant one. EP1–EP3 vary the cross intersection; EL1–EL3 vary transect
half-length (20/30/40 km). Each orthogonal arm is sampled every 10 km.

LATTE is also fitted to the same unique observations for the manuscript's paired
parameter-error comparison. The shared intersection is counted once in LATTE
and outer fits. Positive reported improvement favours DOPPIO. Comparison-table
thresholds are 1 km for centre/Rc, 10⁻⁷ s⁻¹ for rates and 0.005 for aspect ratio;
they exclude negligible differences from percentage comparisons, without
removing the underlying fits or errors.

### LATTE — Figure 11

Configuration: [`latte_idealised.json`](configs/latte_idealised.json).
Four examples use the same elliptical truth as DOPPIO: a sinusoidal transect
(15 points), an illustrative drifter path (30 points), two oblique transects
(10 points each), and a 5×5 grid. Off-grid velocities are interpolated from a
1-km truth grid. The illustrative drifter uses 30 Euler steps of 6,000 s; it
provides a sampling geometry, rather than a high-accuracy trajectory simulation.

### ESP schematic — Figure 1

Configuration: [`schematic.json`](configs/schematic.json).
The schematic illustrates observation selection using circular truth. It uses
40 core and 60 outer draws, a fixed seed and a 1-km sampling grid. It does not
perform parameter estimation.

### Supplementary tests — Figures S1–S3

Both tests use circular stationary truth and fixed sampling geometries. SOLO
uses a single transect, DOPPIO an orthogonal cross, and LATTE nested symmetric
point clouds. Coordinates are reused between experiments; DOPPIO's shared
intersection receives one noisy velocity vector.

| Setting | Supplied configuration |
| --- | --- |
| Sampling extent | 1.2 Rc along transects or radially for LATTE |
| SOLO observations, LOW/MEDIUM/HIGH | 11 / 31 / 101 |
| DOPPIO unique observations | 21 / 61 / 201 (11 / 31 / 101 per arm) |
| LATTE observations | 21 / 61 / 201 |
| Noise standard deviation, per component | 0, 2.5, 5 and 10% of maximum true speed Uref |
| Noise replicates | 100 per nonzero-noise condition |
| Background speed | 0, 5, 10, 20, 30 and 50% of Uref; HIGH density, no noise |
| Background directions | SOLO eastward/northward; DOPPIO and LATTE northward |
| Random seed | 20261027, with separate coordinate and noise streams |

Figure S1 shows median errors and 10th–90th percentile Monte Carlo spread,
not confidence intervals. Figure S2 is deterministic. Figure S3 shows the actual
sampling locations; its HIGH-density configurations also supply the background
experiment. The supplied design produces **2,709 noise records** and **23
background-flow records**, including clean baselines. Every attempt is saved;
failed fits remain unavailable and large valid errors are retained.

The controlled tests use all synthetic observations for inner estimation by
default (`solo_core_radius_m: null` for SOLO), rather than the real-data
applications' restricted inner windows. Outer fits retain their finite-value/sign
filters. `outer_Rc_max_m: null` leaves the fitted radius unbounded. Error scoring
uses final refined Ω; SOLO's aspect ratio is fixed, not independently estimated.

## Saved numerical results

Results stay under `results/experiments/<experiment>/`, separately from PNGs:

| Output | Contents |
| --- | --- |
| `manuscript_summary.md` | Test definitions, settings, numerical results and manuscript-ready tables |
| Parameter/error and manuscript-table CSVs | Full-precision fits, statuses, errors and tabulated results for the relevant group |
| `sampling.csv` | Actual observation locations and selections |
| `run_metadata.json` | Scientific configuration, versions, source/data hashes and provenance |
| `plot_metadata.json` | Rendering settings and hashes of the exported figures |

Main fitted groups also retain `curves.json` and `field.npz`; DOPPIO saves paired
comparison tables. Supplementary groups save every attempt in `trials.csv` and
unrounded statistics/counts in `summary.csv`. The `idealised` command assembles
all four main-group reports into
`results/experiments/idealised_manuscript_summary.md`.

## Redraw or run a different configuration

After a full run, redraw saved results without fitting again:

```bash
python3 experiments/run.py idealised --plot-only
python3 experiments/run.py all --plot-only

# Redraw just S1 and S3.
python3 experiments/run.py noise_sampling --plot-only
```

Plot-only mode checks saved hashes and keeps the scientific configuration frozen,
while applying current presentation settings. It updates PNGs and rendering
metadata; supplementary reports are regenerated from the saved results.
Changing scientific settings or statistical percentiles requires a full run.

Use `--config path/to/config.json` with one named experiment to select another
configuration. To retain an independent run, set `--output-root`; paths are
repository-relative unless absolute. For example, a short supplementary check:

```bash
python3 experiments/run.py all --replicates 2 --output-root results/experiments/smoke
```

The example writes numerical outputs under `results/experiments/smoke/` and PNGs
under `results/experiments/smoke/manuscript_figures/`, keeping them separate from
the default manuscript exports. Rerunning replaces the corresponding outputs.
A short execution check does not reproduce the full supplementary statistics.
